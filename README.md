# Казино-бот для друзей

Telegram-бот на aiogram 3: слот-машина с общим джекпотом, кубик, монетка,
ежедневные награды и «Повторяшка» — бот запоминает фразы из чата и иногда
случайно их цитирует. Есть админ-панель на инлайн-кнопках, доступная только
пользователю с id `1146480839`.

## Структура

```
bot/
├── main.py            # точка входа
├── config.py           # токен, id админа, настройки игр
├── database.py         # вся работа с SQLite
├── requirements.txt
└── handlers/
    ├── economy.py       # /start /balance /daily /top
    ├── casino.py         # /slot /dice /coin
    ├── quotes.py          # повторяшка
    └── admin.py            # /admin — панель
```

## Команды бота

- `/start` — регистрация, выдаёт стартовый баланс (1000 монет)
- `/balance` — баланс
- `/daily` — ежедневная награда (500 монет раз в 24 часа)
- `/slot <ставка>` — слот-машина: анимация 🎰, выигрыш = весь джекпот,
  проигрыш добавляет ставку в джекпот (сумма джекпота показывается перед спином)
- `/dice <ставка> <число 1-6 | чет | нечет>` — кубик 🎲: точное число даёт x5,
  чёт/нечет — x2
- `/coin <ставка> <орел|решка>` — монетка, x2
- `/top` — топ игроков по балансу
- `/admin` — панель управления (только для id 1146480839)

Админ-панель умеет: смотреть статистику, топ, менять баланс любому
пользователю, сбрасывать джекпот, включать/выключать повторяшку, менять её
шанс срабатывания, чистить базу фраз и делать рассылку всем, кто писал боту.

## Настройка

1. Создай бота через [@BotFather](https://t.me/BotFather), получи токен.
2. Открой `config.py` и либо впиши токен прямо в `BOT_TOKEN`, либо (лучше)
   задай переменную окружения `BOT_TOKEN` в настройках хостинга.
3. Id админа уже прописан: `1146480839`. Если нужно другое значение —
   поменяй `ADMIN_ID` в `config.py`.

## Деплой на Bothost.ru

1. Зарегистрируй новый проект типа **Python**.
2. Залей туда всю папку `bot/` целиком, сохранив структуру (`main.py`,
   `config.py`, `database.py`, `requirements.txt`, папку `handlers/`).
3. В настройках проекта:
   - Стартовый файл: `main.py`
   - Файл зависимостей: `requirements.txt` (Bothost сам поставит пакеты при
     старте/деплое)
   - Переменная окружения `BOT_TOKEN` — вставь туда токен от BotFather
     (либо впиши его прямо в `config.py`, если хостинг не даёт задавать env)
4. Запусти проект. Бот сам создаст файл базы `casino_bot.db` рядом с собой —
   отдельно поднимать БД не нужно, файл сохранится на диске хостинга между
   перезапусками (если хостинг не чистит диск при редеплое).
5. Готово — пиши боту `/start` в личке или добавляй в группу с друзьями.

## Важные детали реализации

- Слот-машина и кубик используют **нативные Telegram-стикеры-анимации**
  (`send_dice` с `emoji="🎰"` и `emoji="🎲"`) — это те самые анимированные
  стикеры, которые видно всем в чате, а не рандом «под капотом».
- Джекпот и настройки повторяшки хранятся в таблице `settings` и переживают
  перезапуск бота.
- «Повторяшка» не сохраняет команды (`/...`) и слишком короткие/длинные
  сообщения, чтобы не засорять базу мусором, и не отвечает чаще одного раза
  в 30 секунд на чат, чтобы не спамить.
- Все балансы полностью локальные и не имеют отношения к реальным деньгам —
  просто игровая валюта для фана.
